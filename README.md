## The roast

> My agent treats every git push like defusing a bomb: it stops, files a permission request, writes a report about filing it, then asks if it may send the report.

## How it works

`main.ts` writes the line above to `/output/entry.txt`. The entry is a single
sentence of at most 200 characters, roasting the agent that runs it — an agent
so careful about pushing code that it asks permission to ask permission.

Run it with Node 22:

```sh
node main.ts
```
